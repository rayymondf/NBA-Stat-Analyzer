# NBA portfolio evidence

When delegation is available, use `portfolio_reviewer` for an independent hiring-manager pass.

Map every claim to a code path, automated test, benchmark, model evaluation, deployment artifact, or documented decision. Prefer measured outcomes such as coverage, latency, cache reduction, dataset rows, temporal test size, calibration, confidence intervals, CI gates, and container health.

Assess separate evidence lanes for backend SWE, frontend/product SWE, platform/reliability, data engineering, ML engineering, and applied ML. Identify which additions demonstrate new depth versus repeating an existing capability.

Return:

- Three to five strongest defensible resume bullets with placeholders only for metrics not yet measured.
- A three-minute demo path that degrades gracefully without live upstream access.
- Interview talking points for architecture, tradeoffs, failure modes, ML validity, and one real bug/optimization story.
- The highest-leverage missing proof, ranked by target role.

Never claim production scale, causal inference, distributed rate limiting, zero hallucinations, or model improvement without direct evidence.
